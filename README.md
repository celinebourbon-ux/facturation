# PsyH — Application de facturation

Application statique prête à héberger gratuitement sur **GitHub Pages**.

## Installation sur GitHub

1. Créez un dépôt GitHub, par exemple `psyh-factures`.
2. Ajoutez le fichier `index.html` à la racine du dépôt.
3. Dans **Settings → Pages**, choisissez :
   - Source : `Deploy from a branch`
   - Branch : `main`
   - Folder : `/ (root)`
4. Ouvrez l’URL indiquée par GitHub Pages, généralement :  
   `https://votre-nom-utilisateur.github.io/psyh-factures/`

## Utilisation

- Mot de passe initial : `PsyH2026`
- Modifiable dans **Paramètres**
- Ajout du logo et de la signature dans **Paramètres**
- PDF téléchargeable depuis la facture
- Bouton **Envoyer via Gmail** : Gmail s’ouvre avec le destinataire, l’objet et le message préremplis ; ajoutez le PDF en pièce jointe avant l’envoi.
